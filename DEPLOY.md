# Deployment

Repository: **https://github.com/Afatah01/walhad-carelink** (branch `main`)

## Render.com (one blueprint, one click)

1. Open <https://dashboard.render.com/blueprints> → **New Blueprint Instance**.
2. Connect GitHub and pick `Afatah01/walhad-carelink`. Render reads `render.yaml`.
3. Fill in every value marked `sync: false`:

| Variable | Suggested value |
| --- | --- |
| `APP_BASE_URL` | `https://walhad-carelink.onrender.com` (update after the first deploy if Render picks a different subdomain) |
| `APP_SECRET` | auto-generated by Render (`generateValue: true`) |
| `DEMO_PASSWORD` | a password you choose for the demo accounts |
| `SEED_DEMO` | `true` for a demo, `false` for a real deployment |
| `CONTACT_EMAIL` / `CONTACT_PHONE` / `CONTACT_ADDRESS` / `CONTACT_HOURS` | your real details — anything left blank is simply not shown |
| `TELEGRAM_BOT_TOKEN` | from @BotFather (optional) |
| `VAPID_*`, `TWILIO_*`, `PAYMENT_*` | optional channels |

4. Deploy. Render runs `npm run db:migrate && npm run db:seed && npm start` and health-checks
   `GET /api/health`.

## After the first successful deploy

**Telegram webhook** — the bot needs a public HTTPS URL, so this is a post-deploy step:

```bash
TELEGRAM_BOT_TOKEN=123456:ABC-DEF... \
APP_BASE_URL=https://walhad-carelink.onrender.com \
  npm run telegram:set-webhook
```

Or sign in as the admin account and press **Register webhook** on `/admin` → Integrations.

**Scheduled sync** — add a Render Cron Job:

| Field | Value |
| --- | --- |
| Schedule | `*/5 * * * *` |
| Command | `curl -fsS -H "Authorization: Bearer $CRON_SECRET" $APP_BASE_URL/api/cron/sync` |

Set `CRON_SECRET` on the web service (falls back to `APP_SECRET` when absent).

## Local

```bash
npm install
cp .env.example .env      # set APP_SECRET
npm run db:migrate && npm run db:seed
npm run dev
```
